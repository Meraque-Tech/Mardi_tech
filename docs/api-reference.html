Live counts & history 5

GET/api/counts

Current live per-class detection counts.

GET/api/history

Paginated saved-count history.

query limit (≤5000) · offset
GET/api/path

Recent ENU path-point trace for the UI map/plot.

POST/api/save_count

Save one snapshot of live counts to SQLite.

409 if no live count yet
GET/api/status

Full live-state snapshot, including mjpeg_port.

Auto-save & motion tuning 2

POST/api/auto_save

Toggle forward-only auto-save.

body {"enabled": bool}
POST/api/motion_pos_deadband

Push new deadband distance to the ESKF node via ROS.

body {"deadband_m": float>0}

Detection control 5

POST/api/start

Calls the bed_detection Trigger service; also runs jetson_clocks if on Jetson.

POST/api/stop

Calls the bed_detection_stop Trigger service.

POST/api/reset_tracker

Calls the reset_tracker Trigger service.

POST/api/set_track

Calls the set_tracking SetBool service.

body {"enabled": bool}
POST/api/save

Grab the current MJPEG frame and save it as a JPEG immediately.

Model management 11

POST/api/models/upload

Multipart upload of a .wts file into WEIGHTS_DIR.

POST/api/models/upload_pt

Multipart upload of a .pt file.

GET/api/models

List .pt/.wts/.engine files; includes conversion_supported flag.

GET/api/models/<kind>/<filename>/download

Download a model file.

kind pt · wts · engine
DELETE/api/models/<kind>/<filename>

Delete a model file.

POST/api/models/convertx86 only

Background .pt→.wts conversion via docker run. Returns 400 on Jetson.

body {"filename": "x.pt"}
GET/api/models/convert/status

Poll conversion job status.

POST/api/models/build_engine

Writes wts_name / engine_name / num_class into trt_params.yaml.

body {"filename","num_class"} · 400 if num_class missing/non-positive
POST/api/models/select_engine

Writes engine_name / num_class only.

body {"filename","num_class"}
POST/api/serialize/model

Runs serialize_engine.launch.py in the background (skips if engine file already exists).

POST/api/deserialize/model

Runs bed_detect.launch.py in the background — stops any running serialize first, restarts detection if already running.

GET/api/models/launch/status

Returns {"running","mode","message","ok"}.

GET/api/models/launch/log

Last 500 lines of the current/last ros2 launch subprocess output.

Saved images & reports 5

GET/api/images

List saved JPEGs with metadata.

GET/api/report

Generate and download an HTML QA report — flags low confidence, missing GNSS, near-duplicate positions, no-detection runs.

GET/api/images/download

Stream a ZIP of all saved JPEGs plus images_manifest.csv.

DELETE/api/images/<filename>

Delete one saved JPEG.

DELETE/api/data

Destructive. Disables auto-save, deletes all history rows and all saved JPEGs.

WebSocket 1

WS/ws

On connect, the server sends a full state snapshot. It then pushes {"type":"status"} on detection/tracking/direction/camera-index change, and {"type":"snapshot"} on every class_counts update. Send a ping text frame roughly every 20s to keep the connection alive (30s server-side receive timeout).

State snapshot fields:

ROS 2 service proxying

These endpoints are thin wrappers around ROS 2 services exposed by the yolov8_trt detection node. If the node isn't running yet (before /api/deserialize/model has been called), they return 503.

REST endpointROS serviceROS type
POST /api/start/bed_detectionstd_srvs/Trigger
POST /api/stop/bed_detection_stopstd_srvs/Trigger
POST /api/reset_tracker/reset_trackerstd_srvs/Trigger

curl examples

# Start detection
curl -X POST http://<jetson-ip>:8090/api/start

# Check live status
curl http://<jetson-ip>:8090/api/status

# Toggle auto-save on
curl -X POST http://<jetson-ip>:8090/api/auto_save \
  -H 'Content-Type: application/json' \
  -d '{"enabled": true}'

# Update motion deadband to 0.5m
curl -X POST http://<jetson-ip>:8090/api/motion_pos_deadband \
  -H 'Content-Type: application/json' \
  -d '{"deadband_m": 0.5}'

# Download a QA report
curl -o report.html http://<jetson-ip>:8090/api/report

# Download all saved frames as a zip
curl -o frames.zip http://<jetson-ip>:8090/api/images/download
