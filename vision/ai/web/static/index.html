How to train a model A quick YOLO workflow Step 1 of 5

Follow these steps from left to right. The checklist updates as you work.

  1. 1
    Choose a dataset

    Upload a YOLO ZIP or folder, or select a Roboflow project.

  2. 2
    Prepare and check

    Confirm class names and a 100% split, then prepare the dataset and review warnings.

  3. 3
    Choose settings

    For a safe first run, use Nano, 100 epochs, 640 image size, and pretrained weights.

  4. 4
    Train and monitor

    Click Start and watch the status, metrics, and logs while YOLO trains.

  5. 5
    Review and download

    Compare the evaluation metrics, then download best.pt for deployment.

GPU memory tip: use the Low VRAM preset if training runs out of memory. Larger models and image sizes need more GPU memory.
